## Reproduction and limits

Replay the normalized new suite with:

    python3 scripts/benchmark.py --case-file tests/benchmarks/portfolio-upgrade.json --skill all --output /path/to/new-output

Without an adapter this is a dry run with no score. Supply the configured adapter for real calls. cases.json in this receipt preserves the raw executed fixture and its original hash; portfolio-upgrade.json normalizes role/rubric field names without changing prompts. The original schedule used four workers, seed90722, frozen bodies from 98433f6/current candidates, safe-mode/no tools and a 120-second outer timeout. Tested patches preserve rejected variants; canonical files hold the selected release. Output-only follow-up body hashes differ and their six responses are separate.

No Windows, cloud-account synchronization, every-skill automatic routing or complete multi-turn/rendered-artifact parity is claimed. No remote publication by this root session is implied by local tests or another session's commit.
