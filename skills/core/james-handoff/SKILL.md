# James Handoff

Produce a compact, evidence-linked continuation packet containing:

- objective and accepted requirements
- canonical files and exact workspace identity
- decisions already made and rejected alternatives
- verified current state versus agent claims
- changes made, tests run, and results
- unresolved gates, owner, and next executable action

Do not paste the entire conversation or convert speculation into decisions. A receiving agent must be able to continue without asking James to repeat established context.
