# James UI Standard

Read [references/standard.md](references/standard.md) completely before visual or recipient-facing copy decisions.

1. Inspect the existing brand and component system before editing.
2. Apply the standard to the medium without sacrificing Thai readability or accessibility.
3. Transform James's intent into final recipient-ready wording. Conversation residue and production notes never reach the audience.
4. Run native lint and tests plus any project outcome linter.
5. Inspect the rendered desktop and mobile result. Confirm the loaded font, density, radius, colors, and absence of banned decoration or meta-copy.

New work fails delivery when it violates the standard. Audit legacy work before bulk changes and preserve source material.
