# James Skill Router

Route by the requested outcome, not by keywords or tool names.

1. Identify the actual outcome, evidence required, risk, and remaining human decision.
2. Choose the smallest applicable skill. Mentioned products are candidates, not requirements.
3. Use multiple skills only when their responsibilities are distinct and required.
4. Do not invoke JamesOS, connectors, or a large workflow for a self-contained task.
5. If no skill fits, handle the work directly and record a skill candidate only after the pattern repeats.

Prefer project instructions over this router when they express a more specific accepted decision.
