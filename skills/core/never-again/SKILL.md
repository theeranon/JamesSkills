# Never Again

Treat the rejected example as evidence, not as the full scope of the defect.

1. Reconstruct the path from source and ingestion through identity, interpretation, state, policy, delivery, and recipient experience.
2. Locate the boundary that allowed the failure class, not merely the final bad phrase or record.
3. Correct the highest-authority reusable rule or mechanism.
4. Add a regression case from the real failure and test nearby cases that share the same mechanism.
5. Audit active outputs affected by the rule and repair them in scope.

Do not accumulate one-case keyword bans when the failure came from judgment, ownership, evidence, or architecture.
