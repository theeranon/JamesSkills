# James Visual Standard

- Use IBM Plex Sans Thai for Thai, English, and numbers. Verify the rendered font.
- Use compact, calm, information-dense composition. Body line-height 1.35 to 1.45; dense metadata 1.2 to 1.3.
- Default control height 32px to 38px, panel padding 12px to 16px, and section gap 12px to 20px unless content or accessibility requires more.
- Rectangular surfaces use 6px radius. Truly circular objects remain circular.
- Prefer typography, alignment, grouping, rows, tables, and neutral surfaces over decoration.
- Never use a colored left-edge accent rail on cards, alerts, panels, or list items.
- Use cards only for independent state or interaction. Use pills and chips only for interactive filters, removable selections, or compact status scanned across many rows.
- Keep dates, owners, categories, metadata, and explanation as plain text.
- Use one primary accent per page. Red, amber, and green carry semantic status only.
- Reject decorative gradients, rainbow sections, generic AI-dashboard styling, clipped Thai marks, and unnecessary scrolling.
