# Framework Executive HTML

Produce one compact A4 portrait HTML report. Use the supplied template and adapt its sections only when the decision requires it.

## Required reading order

1. Decision requested and executive recommendation
2. Recurring problem, business reason, and intended users
3. House-library search and use, upgrade, or build decision
4. Research synthesis with competing evidence and limitations
5. Registered name for reuse, or three proposed branded names and one recommendation for a new or materially renamed candidate
6. Visual model, constructs, relationships, and decision logic
7. Scenarios, counter-case, pilot evidence, and success measures
8. Version impact, risks, next validation, and approval
9. Source ledger

The report is the finished decision artifact. Remove prompts, chat residue, internal task narration, and vague claims. Citations must be readable in the report and resolve to the source ledger.

Apply the `make-it-james` standard. Use IBM Plex Sans Thai, compact document flow, 6px rectangular radius, restrained color, plain metadata, and no decorative left rail, gradients, ornamental cards, or unnecessary pills.

For a portable offline file, run the font embedding helper from `make-it-james`. Run strict lint and inspect screen and print rendering before delivery.
