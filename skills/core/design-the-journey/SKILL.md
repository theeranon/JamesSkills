# Design The Journey

Pilot only. Do not present the package name or phase model as an approved general Learning Experience method.

Own the macro architecture of an organization transformation. The journey is not a list of courses. It carries a measurable organization or cohort from a diagnosed starting point through real application, evidence, leadership review, and a next-stage decision.

Read [references/five-phase-model.md](references/five-phase-model.md) only when the request is the sourced SolutionsIMPACT AI Transformation Journey offer or explicitly adopts that pattern.

## Offer-Specific Five-Phase Reference

Use these internal phase identities only for the SolutionsIMPACT AI Transformation Journey offer whose direct source specifies all five:

1. `pre`
2. `workshop`
3. `coaching_consult`
4. `showcase`
5. `after_transformation`

Display labels may be `Diagnose`, `Workshop`, `Coaching`, `Showcase`, and `Transform`. Display wording may change; the responsibility and handoff of each phase may not disappear inside that offer. For a generic transformation journey, derive the architecture from its approved source and keep an unknown phase model unresolved.

## Workflow

1. Establish source authority, sponsor, why now, organization or cohort A and B, business outcome, and credible final evidence.
2. Define baseline, success measures, scope, participant units, program size, cadence, constraints, governance, and decision rights.
3. Lock the approved macro phases before writing a day-by-day agenda. For the sourced AI Transformation Journey offer, map all five phases. Give every phase an objective, input, intervention, output, evidence, owner, and exit handoff.
4. Trace the baseline through the approved phases, participant and work evidence, final consolidation, and next-stage decision. For the sourced AI offer, this runs from `pre` to the Transformation Report.
5. Lock the macro map. Then use `design-the-course` for each workshop day, learning session, or bounded intervention. The child design may refine its experience but may not rewrite the macro journey.
6. Design the operating system around the learning: tracking, coaching, customization, risk escalation, asset ownership, and sponsor reviews.
7. Build the calendar, staffing, readiness, dependency, and fallback plan. Keep commercial assumptions separate from confirmed scope.
8. Specify the final consolidation, leadership decision, organizational assets, and next transformation cycle.

If evidence is incomplete, complete a provisional Journey Skeleton and Decision Brief. Mark missing sponsor, outcome, metric, or client promise explicitly. Do not invent a detailed agenda or call the program ready.

## Required Journey Pack

- authority, assumption, and gap record
- promise traceability ledger linking every promised requirement to its phase, output, evidence, owner, and status
- organization or cohort A and B with business outcome
- baseline and measurement trace
- complete approved macro map; use the five-phase map only for the sourced AI Transformation Journey offer
- program calendar and cadence
- workshop-day briefs for `design-the-course`
- coaching, project tracking, and customization plan
- evaluation or showcase criteria and leadership decision packet
- governance, owner, staffing, asset, dependency, and fallback map
- final evidence-report specification and next-stage decision; use a Transformation Report for the sourced AI offer

## Ready Gate

Call the journey ready only when:

- every phase has a purpose, accountable owner, evidence, and handoff
- each workshop output feeds the next day or phase
- coaching moves work from intention toward implementation
- evaluation criteria reflect the promised outcome rather than presentation polish
- the final evidence report traces back to the baseline and supports a real sponsor decision
- every promised requirement is mapped, transformed, deferred, or rejected explicitly
- all bounded learning interventions pass `design-the-course` quality without fragmenting the macro journey
- no old phase model, unsupported framework label, or unconfirmed promise has been presented as approved

For the sourced SolutionsIMPACT AI Transformation Journey offer, also require `pre` findings to change workshop scope when needed, all five phase handoffs, showcase evidence, and a final Transformation Report.
