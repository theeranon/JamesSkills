# Wealth Dynamics / Talent Dynamics Applications

## Evidence required first

- User-declared official result, if one exists, with assessment date and version.
- Repeated observed behavior across more than one context.
- Work the person starts, sustains, completes, avoids, or returns to others.
- Actual role outcomes, communication failures, energy drains, and support conditions.
- A competing explanation such as skill gap, unclear authority, overload, incentives, or environment.
- The application context: entrepreneurial value creation or team and organizational work.

## Core questions

1. Which work conditions repeatedly produce strong output with less friction?
2. Which contribution is trusted because evidence shows consistent delivery, not because a profile says so?
3. What role or communication experiment follows from the lens?
4. What alternative explanation fits the same behavior?
5. What result would make us revise or discard the profile hypothesis?

## Reversible experiments

### Role-fit test

For two weeks, move one bounded responsibility toward the contribution pattern the lens predicts. Keep authority, outcome, deadline, and support explicit. Measure cycle time, quality, rework, and reported energy. Retain the lens only if the measured result improves.

### Communication test

Present the same bounded decision in two formats suited to plausible preferences, such as concise visual direction versus written detail and metrics. Measure comprehension, response time, and execution errors. Do not convert one response into a permanent type.

### Team-gap test

Map required contributions for one project before mapping people. Assign from observed capability and consent, then use profile language only as a secondary hypothesis. Review after the project rather than treating the initial map as truth.

## Decision output

Return: declared result or `unknown`, observable evidence, plausible profile or frequency hypothesis, alternative explanation, experiment, metric, duration, and revision trigger.
