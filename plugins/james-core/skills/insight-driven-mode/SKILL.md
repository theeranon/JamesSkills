# Insight Driven Mode

Trace every customer-facing line to a written insight for one named group.

## Scope

- Kind: mode
- Owns: the insight-first order for customer-facing marketing, brand, content and copy for the rest of the conversation — one written insight per target group, then the strategy, channels and copy that cite it.
- Boundary: changes the order and the evidence required before customer-facing writing. Never invents quotes, numbers or customer facts, never widens authorization, and never replaces the skill that owns wording, outside evidence, option comparison or the deliverable.

## Works with

- For who decides the next action while this order stays active -> `proactive-habits`
- For wording of copy that already cites its insight line -> `make-it-james`
- For how the reply is shaped, without dropping a group's insight line -> `i-have-adhd`
- For one outside claim the insight depends on -> `research-it`
- For comparing options once an insight exists -> `give-me-solutions`
- For finishing an agreed customer-facing task while this order stays in force -> `done-for-me`

## Do not use this when

- The only job is to settle one outside claim, with no customer-facing marketing or copy -> `research-it`
- The only job is to compare options and recommend one -> `give-me-solutions`
- The reader needs a shorter reply and no marketing, brand or copy sequence is in play -> `i-have-adhd`
- The missing piece is who decides the next action, not which insight the copy traces to -> `proactive-habits`

## Behavior

Nothing customer-facing is written until each target group has a written insight it traces back to. The insight sets strategy and direction. Each later step waits until the previous step is done for every group.

1. **Groups.** Use the groups the user already agreed, and cite that source. If none exist, propose the best-supported set and ask once. Do not re-ask groups, positioning or bans that are already settled.
2. **Insight.** One page per group: who they are and the situation they are in; what they already tried; the real tension they cannot say out loud; the hidden belief that blocks them; what they want to be true; their own words, as real quotes with a source, with inference labelled as inference; and one core insight sentence in their language.
3. **Strategy.** For each group, from its own insight: what they must come to believe, the proof that belief needs, the entry offer and the call to action named from the insight, and what to say and never say.
4. **Channels.** One plan per group, never one shared plan. Each group gets its own landing page and its own article column, with that column's name, promise, topics and voice. Split ads, outreach and social by group.
5. **Copy last.** Every headline, title and call to action cites its insight line. Test three-second understanding, native wording rather than translation, and whether the group sees itself. Show only the lines that pass.

When copy fails, fix the insight, not the words. One message per group; a message aimed at everyone is a defect. Never invent a quote, a number or a customer fact. Work done before the insight exists is marked superseded, not deleted, and then rebuilt from the insight.

## Stays active until

The user turns it off. Switching tasks inside the same project does not end it, and finishing one deliverable does not end it. It does not carry into an unrelated conversation.

## Principles

**Jobs to be done** — Start from the progress a group is trying to make in a specific situation, including what they already tried and the tension that blocks them. Source: Clayton M. Christensen, Taddy Hall, Karen Dillon and David S. Duncan, Competing Against Luck, 2016
**Segment before message** — Settle who the group is before writing what they should hear; one message for everyone is a defect. Source: Philip Kotler, Marketing Management, segmentation-targeting-positioning

## Counter-case

- The user explicitly asks for quick copy and says not to do the insight work. Write that copy now; do not block it on an insight page. `make-it-james` still words recipient-facing text.
- The writing is non-customer-facing internal notes, a working draft or a code comment. Do not impose groups, insights or channel plans on it.
- An audit-only request is complete when it reports, for each named group, whether a written insight exists and which lines trace to it. Do not rebuild the artifact.

## Hand back

The requested deliverable, with each customer-facing piece traced to one insight line for one named group. An explicit quick-copy or audit-only request returns only what that request asked for.
